# Task Manager Flask App

A simple and modern Task Manager web application built with Flask and SQLite.

## Features

- User Registration
- User Login & Logout
- Add Tasks
- Edit Tasks
- Delete Tasks
- Task Priorities (High, Medium, Low)
- Responsive Dashboard
- SQLite Database

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- Bootstrap

## Installation

Clone the repository:

```bash
git clone https://github.com/Nobody07/TaskManager.git
```

Go to project folder:

```bash
cd TaskManager
```

Install dependencies:

```bash
pip install flask
```

Run the application:

```bash
python app.py
```

Open:

```text
http://127.0.0.1:5000
```
